# Публикация Nightweave на GitHub Pages

Сайт полностью статический: HTML, CSS, JavaScript и локальные файлы каталогов, изображений, шрифтов и QR-библиотеки. Генерация неба, проверка ответов, QR и PDF выполняются в браузере. База данных, серверная программа, npm и сборка для публикации не нужны. `server.mjs` в архиве исходников — только необязательный локальный HTTP-предпросмотр для разработки.

## Самый простой способ — через сайт GitHub

1. Распакуйте `nightweave-github-pages.zip`. Внутри находятся `index.html`, `quiz.html`, файлы JavaScript/CSS, папки `assets` и `vendor`, файл `.nojekyll`. Это уже готовый сайт.
2. На GitHub создайте новый публичный репозиторий, например `nightweave`.
3. В репозитории выберите **Add file → Upload files**. Загрузите **содержимое распакованной папки**, включая обе вложенные папки и `.nojekyll`. Не загружайте ZIP как единственный файл. `index.html` должен оказаться непосредственно в корне репозитория, а не в дополнительной папке `dist` или `nightweave-github-pages`.
4. Сохраните изменения кнопкой **Commit changes** в ветку `main`.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** укажите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)**. Нажмите **Save**.
6. Дождитесь завершения публикации. Адрес появится на той же странице. Для репозитория `nightweave` это обычно `https://USERNAME.github.io/nightweave/`. Статус публикации можно посмотреть во вкладке **Actions**.
7. Откройте сайт по выданному HTTPS-адресу. Квизы доступны по `quiz.html` в той же папке. Впоследствии обновляйте файлы в `main`; GitHub Pages перепубликует сайт.

GitHub Pages также поддерживает корневой сайт `https://USERNAME.github.io/`, если репозиторий называется `USERNAME.github.io`, и собственный домен. Переписывать код сайта для этих адресов не нужно.

## Проверка после публикации

- Откройте тренажёр, затем квизы и каталог. Звёздные карты и шрифт греческих символов должны загрузиться.
- Введите `Q12345` в поле seed тренажёра: должна открыться страница квиза **внутри того же репозитория**. Введите `T12345` на странице квиза: должен открыться тренажёр.
- Скопируйте ссылку и проверьте, что она начинается с вашего адреса GitHub Pages и содержит имя репозитория, если сайт размещён в подпапке.
- Скачайте PDF и отсканируйте QR на телефоне: он должен открыть этот же GitHub Pages, нужный seed и настройки.
- В песочнице выберите «Обозначения Байера»: буква выбирается из списка, индекс можно оставить пустым, созвездие вводится вручную. Затем добавьте опорную точку — предыдущая отметка должна сохраниться.
- Нажмите «На весь экран» у карты тренажёра: список объектов, переключение заданий и параметры должны остаться доступны. Проверьте увеличение, режим «Перемещать», постановку точки и выход кнопкой «Закрыть» или Escape. Карты-искатели каталога и иллюстрации квизов тоже разворачиваются.

Полноэкранный режим не требует новых настроек GitHub Pages. Где браузер поддерживает нативный Fullscreen API, используется он; в остальных случаях карта занимает всё окно страницы. Дополнительные разрешения, сервер или зависимости не нужны.

История и текущие ответы хранятся в localStorage браузера. При переезде с прежнего домена на GitHub Pages браузер создаст отдельное локальное хранилище: старая история автоматически между доменами не переносится. QR и новые ссылки всегда используют адрес открытой страницы; внешнего сервиса QR нет.

## Если удобнее через Git

Откройте терминал в распакованной папке готового сайта. Создайте на GitHub пустой репозиторий без автоматически добавленных файлов, затем выполните:

```sh
git init -b main
git add .
git commit -m "Publish Nightweave"
git remote add origin https://github.com/USERNAME/nightweave.git
git push -u origin main
```

Замените `USERNAME` и имя репозитория своими значениями. Авторизуйтесь стандартным способом GitHub. После отправки файлов включите Pages, как описано в шагах 5–6.

## Если сайт не открывается

- Ошибка 404 на главной: проверьте, что `index.html` лежит в корне выбранной папки публикации и ветка указана правильно.
- Ошибка 404 у квизов: используйте ссылку `quiz.html`, а не `/quiz` от корня домена. Встроенные ссылки уже настроены правильно.
- Не загружаются файлы: проверьте загрузку папок `assets` и `vendor`, сохранение регистра имён и наличие `.nojekyll`.
- При открытии двойным щелчком как `file://` каталог может блокироваться браузером. Проверяйте сайт через GitHub Pages или необязательный локальный HTTP-предпросмотр.

Официальные инструкции GitHub: [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) и [создание сайта Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
